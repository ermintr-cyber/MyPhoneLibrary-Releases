# MyPhoneLibrary 1.11.0

- Combined Brand, Color, Operating system, Location and Condition filters. All chosen criteria must match the same unit.
- Search model/variant, type code, product code, IMEI and battery with tolerant spacing and punctuation.
- Select a main personal photo for each phone; model image remains independent.
- Save and add another preserves variant/color/OS while clearing physical identifiers, photos, notes and condition for the next unit.
- Backup settings show last attempt and last successful backup separately for both saved locations.
