# MyPhoneLibrary 1.26.0

- Each physical phone has an explicit review state: Needs review or Fully checked, with its confirmation timestamp saved in the library.
- Add/Edit phone: Save as fully checked confirms only that unit. Resolve all model and unit To check flags first. Ordinary Save never automatically certifies a phone.
- Phones to complete in the sidebar (also Android More) lists only active units awaiting review, with direct Review phone buttons. My collection retains the full collection with compact review badges.
- Reopen review is available in the editor. Changes to unit data reopen that unit; changes to shared model details reopen affected units. Copied phones begin unchecked. Legacy records remain unchecked until explicitly reviewed.
- Existing data, backups and independent Windows/Android updates are preserved.
