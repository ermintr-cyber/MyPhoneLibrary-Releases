# MyPhoneLibrary 1.9.0

- Quick edit color, edition, operating system, working condition, location and box directly in an expanded phone row. Save or cancel inline; Enter and Escape are supported.
- Select units across models and update chosen fields together. The operation is atomic and rejects stale revisions without overwriting other edits.
- Battery, charger and part-category catalogs support explicit compatible models and show linked stock, availability and locations. Parts can select their catalog object.
- Completeness distinguishes missing accessories from unchecked ones, with an Incomplete sidebar filter and optional table column.
- Locations have parent locations with cycle validation and a contents view including descendant locations.
- Duplicate IMEI warnings cover other models, both IMEI fields, units of the same model and Trash. Open the existing unit or deliberately confirm saving.
- Click a unit image or inventory number to view its gallery, details, acquisition, completeness, notes, repairs and model history.
- Group inventory cells show a dash and the column is narrower. Catalog categories are arranged in one vertical list.
