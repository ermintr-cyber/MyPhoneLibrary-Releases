# MyPhoneLibrary 1.8.0

- Individual phones align with the summary table columns and can override variant, type code, operating system and GSM/Wikipedia links.
- Summary rows aggregate effective unit values. Color spelling and capitalization are preserved.
- Remember me keeps a browser signed in for 30 days across server restarts and updates; logout/password changes revoke it.
- Backup creation, downloads and restore are inline in Settings → Backup. Password and custom-field settings are inline too.
- Windows data moves to C:\ProgramData\MyPhoneLibrary after database and file verification. The legacy data is retained. Custom data paths are preserved.
- Migration-aware update status bridges the old updater's status file so completion can be confirmed without manual refresh.
