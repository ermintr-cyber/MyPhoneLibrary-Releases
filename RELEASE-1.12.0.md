# MyPhoneLibrary 1.12.0

- Dedicated battery specifications and automatically linked phone models.
- MyMediaLibrary-style settings, theme tiles, default page/view, display density and aligned network/backup/about screens.
- Combined offline Windows installer offers Media, Phone or both, preserving separate collections.
- Native Android client with local/Tailscale connections, QR setup, camera/gallery uploads and remembered login.
- Separate combined Android installer contains both original signed application packages and uses Android confirmation for each.
