# MyPhoneLibrary 1.10.0

- Hide/show navigation from the top menu button; remembers the choice in this browser.
- Catalog fields use full-width searchable dropdowns with selection restricted to existing catalog entries, including quick/bulk edits.
- New units suggest the next free positive inventory number; automatic server allocation avoids occupied numbers.
- One continuous phone form with one variant, type code, OS and link field; individual unit overrides remain independent.
- One Notes field and one Photos of this phone area; shared model image stays at the top and existing model galleries remain stored.
- Catalogs expand inline in a full-width vertical accordion, one category at a time.
- Existing records, photos and legacy notes are retained.
